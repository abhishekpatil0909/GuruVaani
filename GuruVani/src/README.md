# src

Clean Architecture layout for GuruVani.

- Guruvani.Api/: Web API (Controllers, Middlewares, Swagger)
- Guruvani.Application/: Application services, DTOs, Validators, Mappings
- Guruvani.Domain/: Entities, Enums, ValueObjects, Base
- Guruvani.Infrastructure/: Persistence, Repositories, Payments, Notifications, DependencyInjection
